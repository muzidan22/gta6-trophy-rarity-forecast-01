A standard-library Python program that reads a case of Exophase trophy reads and forecasts five quantiles of every Grand Theft Auto VI trophy's earn rate at the case's target, fitting each trophy's logit rate as a damped log-time trend with an honest random-walk spread.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output python3 -P -s main.py
```
